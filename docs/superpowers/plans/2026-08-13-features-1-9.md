# Features 1–9 Implementation Plan

> **For agentic workers:** Implement task-by-task. Push to `main` when the batch is done (auto-push rule).

**Goal:** Ship the nine recommended improvements on PTS Learning with minimal disruption to existing flows.

**Architecture:** Prefer wiring existing APIs (`createNotification`, payments admin UI, reviews, Drive `tryUploadLocalFile`, LineApp) over greenfield. Add small tables/scripts only where missing (audit log, Drive migrate, smoke tests).

**Tech Stack:** Express, SQL Server, vanilla frontend HTML/JS, optional Playwright/`node --test`.

## Global Constraints
- Keep local `uploads/` as source of truth for display; Drive remains backup.
- Do not force-push `main`.
- Thai UI copy consistent with existing Admin/Community pages.
- No secrets in commits.

---

### Task 1 — Notifications (like/comment + course starting soon)
- Wire `createNotification` on community like/comment (not self).
- Add lightweight interval/cron: schedules within ~24h → notify enrolled users (dedupe via recent notification or flag).
- Improve payment-approved copy if easy.

### Task 2 — Courses search + filters
- Client search (title/description), price min/max, keep mode filter; category chips if `coursescat_id` present.

### Task 3 — Admin slip lightbox
- Modal preview on slip click; keep approve/reject; optional “pending oldest” already exists.

### Task 4 — Public learner profile
- `GET /api/users/:id/public` + `User.html` + Community author links.

### Task 5 — Reviews after completion
- Gate `canReviewCourse` on enrolled+paid **and** progress ~100% (or completed status).

### Task 6 — LINE/LIFF shortcuts
- Clear buttons/links: คอร์สของฉัน, ชำระเงิน, แจ้งเตือน, คอมมูนิตี้ in `LineApp.html`.

### Task 7 — Bulk Drive migrate script
- `scripts/migrate-uploads-to-drive.js` for avatars/slips/community/hero/cert.

### Task 8 — Admin audit log
- Table + `writeAudit` on payment approve/reject and course create/update/delete; Admin tab list.

### Task 9 — Smoke tests
- `tests/smoke.test.js` or Playwright: health + login page + courses API (expand if creds available).
