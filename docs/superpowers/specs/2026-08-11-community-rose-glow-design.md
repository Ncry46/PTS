# Community Rose Glow (red-forward) visual polish

Date: 2026-08-11

## Goal
Make Community page more visually appealing with stronger red brand presence and clearer focal points, without changing the working 2-column layout or post/image/feeling features.

## Direction
Rose Glow with redder emphasis (`#ca1156` → `#9b0d42` / `#e11d48` accents).

## Scope
- `frontend/Community.html` page-local CSS + light class/markup polish only
- Keep: feed + composer left, sticky sidebar right, hero above
- Keep: feeling picker, image upload, likes/comments APIs

## Visual changes
1. Page background: pink–red radial washes
2. Hero: saturated red gradient, white type, soft glow motion
3. Cards: warm white, rose borders, red-tinted hover lift
4. Composer: red top accent bar, stronger primary CTA
5. Sidebar CTA: red left rail; trending tags with red labels
6. Motions: hero fade-in, card stagger, hover lift (subtle)

## Out of scope
Schema/API changes, layout restructure, other pages
